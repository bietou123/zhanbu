# 八字命理排盘与流年推演

高精度全栈八字排盘系统，纯 HTML/CSS/JS（无任何依赖），浏览器双击 `index.html` 即可运行。

## 快速开始

```bash
# Windows：双击 index.html 即可
# 或用本地服务器：
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 核心特性

### 1. 高精度天文引擎
- **节气计算**：VSOP87 截断算法 + Meeus 章动/光行差/FK5 修正
  - 1900-2100 年范围精度 < 1 分钟
  - 1989/2024 立春计算与紫金山天文台数据偏差 < 30 秒
- **ΔT (TT-UT)** 修正：Espenak-Meeus 多项式
- **真太阳时**：均时差 (EoT) + 经度修正，与天文台数据一致

### 2. 历史夏令时
内置中国 1986-1991 夏令时数据，自动校正：
- 1986: 5/4 - 9/14
- 1987: 4/12 - 9/13
- ...
- 1991: 4/14 - 9/15

### 3. 严谨的命理算法
- **年柱切换**：立春时刻（非农历正月初一），精确到秒
- **月柱切换**：12 个"节"，五虎遁定月干
- **日柱切换**：真太阳时 23:00（晚子时算次日流派）
- **时柱**：12 时辰按真太阳时切分，五鼠遁定时干
- **大运**：阳男阴女顺、阴男阳女逆，起运精确到日（3天=1岁）

### 4. 关系规则引擎
图论 + 优先级解析，不是 if-else 海：
- 天干五合、相冲
- 地支六合、六冲、六害
- 三合局、三会方、三刑、自刑
- **"合解冲"优先级**："贪合忘冲"
- **"三合 > 六合"**：局成则忽略单字小合

### 5. 流年时间轴
拖拽时间轴（0-120 岁）实时观察：
- 当前大运 / 流年干支
- 流年与原局产生的新合冲关系（实时画线 + 高亮）

## 自测

```bash
node test-node.js
```

输出会涵盖：
- 节气精度（与紫金山天文台对比）
- 均时差精度
- 立春边缘 ±2 分钟切换测试
- 日柱锚点
- 夏令时
- 大运排布
- 关系规则引擎

## 精度限制 / 已知边界

- **节气**：1900-2100 内精度 < 1 分钟。极端边缘（节气前后 30 秒内出生）建议查紫金山天文台权威数据双重确认
- **DST**：仅内置中国 1986-1991。其他国家/年份的夏令时需在输入时手动减/加 1 小时
- **神煞**：仅实现 天乙贵人、桃花、驿马、华盖、文昌 五个常用神煞
- **南半球反月模式**：实验性功能（业内有争议）。默认关闭
- **格局**：未做格局判定（杀印相生、伤官配印等），仅基础排盘
